# Licenses, notices and source provenance

Trickee-owned code uses the repository [Apache-2.0 LICENSE](../LICENSE). Official AOSP source is fetched separately and retains upstream licenses and notices; its manifests and service source are not re-licensed by Trickee. See the pinned revisions in [ARCHITECTURE.md](ARCHITECTURE.md).

| Material | Source and handling |
| --- | --- |
| Official AOSP manifest, Car Service and automotive hardware interfaces | `android.googlesource.com` checkouts in `aosp/upstream`; preserve each upstream LICENSE/NOTICE. |
| Python packages | Exact versions in `requirements.lock`; server/web CycloneDX inventory in `docs/SBOM.cdx.json`. Review license terms before release. |
| Android libraries and Gradle wrapper | Official Gradle and Maven dependencies; the existing SBOM does **not** enumerate the Android resolved graph. Generate and review that inventory before distribution. |
| Syne, Manrope and Michroma fonts | Existing Trickee design assets; corresponding SIL OFL notices at `fleet-console/assets/OFL-syne.txt`, `OFL-manrope.txt`, and `OFL-michroma.txt`. Native driver font conversions use the same families. |
| Leaflet 1.9.4 JS/CSS and markers | Bundled with BSD-2-Clause notice at `fleet-console/assets/leaflet/LICENSE`. |
| Trickee logos and vehicle imagery | Reused from the former Trickee project's assets; project ownership and distribution rights should be confirmed for the final package. |
| OpenStreetMap demo tiles | External, attributed, best-effort demonstration under the [OSMF tile policy](https://operations.osmfoundation.org/policies/tiles/). Production requires an approved licensed or self-hosted tile service. |
| OSRM-compatible routing | Optional external provider; no OSRM server or road dataset is bundled. Review provider and data licenses for deployment. |

The server/web SBOM is generated by `python scripts/build_sbom.py`. It covers locked Python packages and vendored Leaflet assets, **not** all code, Android dependencies, fonts, AOSP source or external services. Treat it as a partial inventory.
